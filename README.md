# OpenMooring ⚓

OpenMooring è uno strumento open-source scritto in Python per l'analisi statica del bilancio delle forze e la distribuzione del carico sulle linee di ormeggio delle navi, sviluppato seguendo i principi guida **OCIMF MEG4**.

## Caratteristiche
- Calcolo delle forze ambientali (vento e corrente) secondo le formule aero/idrodinamiche OCIMF.
- Risoluzione della matrice di rigidezza 2D per la ripartizione dei carichi sui cavi attivi.
- Interfaccia grafica interattiva sviluppata in Streamlit.
- Monitoraggio delle soglie di sicurezza operative (limite 50% MBL).
